Spore Swab Labels

Standalone swab-collection labels — no login, no cloud, works offline. Fill a line per genetic, then Print → DYMO LabelWriter (2.25″ × 1.25″). Margins None, Scale 100%, Background graphics On.

Phone + Bluetooth label maker? Use Share on a label (or Share all) to send the PNG straight to Messages / AirDrop / your printer app. On desktop, Save PNGs then text/AirDrop them to your phone.

Lot IDs run SW-CODE-YYMMDD-NN starting at Start #. If you already printed swabs for this code today (in the app or here), bump Start # so numbers don't collide — this page can't see the app's counters.
